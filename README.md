# House of Quants

**Quantitative Research & Solutions**

House of Quants is an independent research publication focused on systematic investing, portfolio construction, quantitative methods, research infrastructure, and AI-enabled analytical workflows.

The goal is simple: publish clear, practical research and selected tools that connect quantitative ideas with real-world implementation.

Most production systems and proprietary research remain private. Public material may include research notes, methodology, charts, notebooks, and selected code examples.

## Site

This repository powers the House of Quants website with MkDocs Material and GitHub Pages.

## Structure

- `docs/research/` — longer research notes and studies
- `docs/notes/` — shorter observations, methods, and ideas
- `docs/code/` — selected code examples and notebooks
- `docs/about.md` — background and scope

## Local preview

```bash
pip install -r requirements.txt
mkdocs serve
```

Then open `http://127.0.0.1:8000`.
